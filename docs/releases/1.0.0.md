# EasyPrivacy V1.0.0

Release designation: October 19, 2026. First MVP accepted by the owner on
October 18, 2026 after testing the working setup.

## Release scope

V1.0.0 combines secure enrollment, remembered device identity and revocation,
Windows/Android VPN clients, a VPS exit, and a home VM exit reached through the
VPS. The Ubuntu node package supports core and outbound service-node roles.
Headless setup and optional Linux GUI controls operate the same home service.
Management host routes handle overlapping local/home LAN ranges.

Both VPN legs are encrypted. The VPS decrypts and re-encrypts forwarded packets
and remains trusted. HTTPS and SSH provide their own protection beyond the home
exit; plain HTTP is unencrypted after leaving that exit. Selected Home traffic
cannot silently fall back to the VPS exit when the home path is unavailable.

## Release versions and files

The project release, core binary, Debian packages and native pairing crate use
`1.0.0`. Flutter uses `1.0.0+7`: the user-facing version is `1.0.0`, and Android's
monotonically increasing build counter is `7`. Windows version resources derive
their values from the same Flutter release. `VERSION` is the package-build
default; explicit build overrides remain available for development.

| Component | Release file |
| --- | --- |
| Ubuntu amd64 core / service node | `core/dist/easyprivacy-node_1.0.0_amd64.deb` |
| Ubuntu arm64 core / service node | `core/dist/easyprivacy-node_1.0.0_arm64.deb` |
| Optional Ubuntu amd64 GUI | `app/build/easyprivacy-desktop_1.0.0_amd64.deb` |
| Windows x64 app | `app/build/easyprivacy-windows-1.0.0-x64.zip` |
| Android app | `app/build/easyprivacy-android-1.0.0.apk` |

Release files have matching SHA-256 sidecars. The normal Flutter APK output is
also available at `app/build/app/outputs/flutter-apk/app-release.apk`.

Dependency versions, API/PAKE protocol versions, native helper IPC revision and
saved-state schemas are independent of the product release. They retain their
existing values so the version designation does not change compatibility.

## Upgrade an existing MVP installation

Disconnect the VPN before upgrading the node network helper. Copy the matching
node package to both the VPS and home VM, and run on each:

```bash
sudo apt install ./easyprivacy-node_1.0.0_amd64.deb
easyprivacy-node version
```

Use the arm64 filename for an ARM64 machine. Upgrades preserve core identity,
account credentials, enrolled devices, VPN keys and service configuration. Keep
the existing setup; there is no need to rerun `setup`, `vpn-setup`, `service-setup`
or enrollment to change the release designation. Configured services restart.

Extract the complete Windows ZIP and launch `easyprivacy.exe`. Install the Android
APK as an update using the same signing identity. For an existing Linux desktop:

```bash
sudo apt install ./easyprivacy-node_1.0.0_amd64.deb ./easyprivacy-desktop_1.0.0_amd64.deb
```

New installations should follow the [core guide](../../core/README.md) and
[home service-node guide](../home-service-node.md).

## Validation and limits

The owner accepted the working MVP on the actual deployment. Its implementation
checks include core race tests and vet, enrollment interoperability and relay
rejection, Flutter tests and analysis, Windows helper authentication, isolated
real-kernel WireGuard/NAT/DNS/LAN/overlap/outage/revocation tests, and Ubuntu package
installation/upgrade/removal checks.

V1.0.0 release checks passed on October 19, 2026:

- Core Go tests and vet, Flutter analysis, and all 32 app tests.
- Both node architectures, the Linux GUI, Windows ZIP and Android APK built
  successfully; package metadata and all five SHA-256 sidecars were verified.
- The Windows executable reports `1.0.0+7`; Android reports version `1.0.0`,
  build counter `7`, and passes 16 KB APK alignment checks.
- Ubuntu 24.04.4 amd64 clean installation, upgrade from the preceding MVP package,
  removal, reinstall and purge passed in a disposable root. Identity, credentials
  and device records were preserved. These checks did not alter the working VPS,
  home VM or phone installation.

- One owner account and one home service-node exit are supported.
- Client Internet traffic uses IPv4; IPv6 is captured and blocked while connected.
- The optional Linux GUI manages a service node. An ordinary Linux full-tunnel
  client remains future work.
- Boot-time client VPN auto-connect, optional pairing-code PIN protection,
  certificate renewal and account recovery remain future work.
- ARM64 node packages are cross-compiled; actual ARM64 Ubuntu hardware validation
  has not been recorded. The optional GUI release is amd64.
- The Android APK retains the existing development signing key for local use.
  Packages are distributed as manual downloads, not through a signed APT repository.
- This release designation does not claim an independent security audit.
